# PvZ Column Like You See Em

### Gameplay

* _Almost all plants are priced times 5/6 (depending on the level pool/fog or the rest)_

* Puffshroom has 5x cooldown_

* Iceshroom freezes for 5x longer_

* Blover blows fog for 6x longer_

* _Zombies are 3x more powerful in general_

* _There is 3x less chance zombies drop coins_

* _Conveyor belts are slowed down by 2x except in Bungee Blitz which is actually sped up by 4x (you will see why)_

> [!TIP] Use W key to toggle fast mode for convenience
>
> [!TIP] Use Seed Bank Keybinds on 0-1 Mode since I fixed a bug where you couldn't choose the last seed
