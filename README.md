# PvZ Column Like You See Em

### Gameplay

* _Almost all plants are priced times 5/6 (depending on the level pool/fog or the rest)_

* _All plants have 2x cooldown_

* _Zombies on most challange levels has 6x more points ¹_

* _Zombies on normal levels have 2x more points ¹_

> 1. Zombie Points is on what the code determine how to spawn zombies. Either the quantity or quality (cone-heads over normal zombies), so in general it should be 2/6x harder
